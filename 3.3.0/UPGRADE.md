# Upgrade Guide

## Міграція з 3.2.x до 3.3.0

### Увага!

Версія 3.3.0 містить значні архітектурні зміни та не є повністю сумісною з гілкою 3.2.x.
Оновлення виконується як міграція, а не як звичайне оновлення модуля.

### Перед встановленням 3.3.0 рекомендується:

1. Зробити резервну копію файлів і бази даних.
2. Видалити модуль версії 3.2.x.
 - Виконати: 
   php bin/magento module:disable PortmonePayment_Portmone
- Видаліть папку:
   app/code/PortmonePayment/Portmone/  
4. Встановити модуль 3.3.0.
